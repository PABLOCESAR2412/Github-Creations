# ⚡ GITHUB STATS GENERATOR [ BRUTALIST EDITION ]

A brutalist, real-time, interactive GitHub Profile README generator. Built with React, Vite, and Tailwind CSS.

## 🚀 Features

- **Brutalist UI**: A dark, neon-cyan, terminal-inspired interface.
- **Dynamic Stats**: Fetch your latest GitHub repositories, followers, and language stats.
- **Component Builder**: Easily arrange badges, stats cards, language tables, and activity graphs via drag-and-drop.
- **Live Preview**: See exactly how your Markdown will render on GitHub.
- **Vercel API Exporter**: Automatically generate Node.js serverless code so you can host your own 100% custom SVG stats endpoints on Vercel for free.
- **GitHub Actions Automation**: Automatically generate YAML workflows and update scripts to keep your README stats fresh every 6 hours without needing a dedicated server.

## 💻 Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Framer Motion
- **State Management**: Zustand
- **Markdown**: react-markdown

## 🛠️ Installation & Setup

1. Clone the repository:
   \`\`\`bash
   git clone https://github.com/PABLOCESAR2412/Github-Creations.git
   \`\`\`

2. Navigate to the project directory:
   \`\`\`bash
   cd Github-Creations
   \`\`\`

3. Install dependencies:
   \`\`\`bash
   npm install
   # or
   bun install
   \`\`\`

4. Run the development server:
   \`\`\`bash
   npm run dev
   # or
   bun run dev
   \`\`\`
